# 📘 Product Requirements Document (PRD)
## Raise Me Coaching Centre Management App

---

## 1. 📌 Overview
The Raise Me Coaching Centre Management App is a web-based platform designed to streamline student management, communication, content delivery, and administrative workflows for coaching institutes.

---

## 2. 🎯 Objectives
- Simplify student data management
- Automate fee reminders via WhatsApp
- Provide centralized content delivery (notes, syllabus, videos)
- Enhance communication between teachers and students
- Deliver a clean, modern, and professional UI

---

## 3. 👥 User Roles
### 3.1 Admin
- Manage students, teachers, and system settings

### 3.2 Teacher
- Upload notes, syllabus, notifications, and video lectures

### 3.3 Student
- View notes, syllabus, notifications, and videos

---

## 4. 🚀 Core Features

### 4.1 Student Management
- Add new student details:
  - Name
  - Phone Number
  - WhatsApp Number
  - Course Enrolled
  - Fees Status
- Edit/Delete student profiles
- Search and filter students

---

### 4.2 WhatsApp Fee Reminder System
- Add WhatsApp number for each student
- Send:
  - Monthly fee reminders
  - Payment confirmations
- Auto-reminder scheduling
- Predefined message templates

---

### 4.3 Notifications & Study Materials
Teachers can upload:
- Exam notifications
- Syllabus updates
- Notes (PDF, DOC)

Students can:
- View/download materials
- Receive alerts for new uploads

---

### 4.4 Video Lecture Module
- Upload recorded video lectures
- Categorize by subject/course
- Streaming support
- Student dashboard for viewing

---

## 5. ✨ Additional Professional Features

### 5.1 Dashboard
- Overview of:
  - Total students
  - Pending fees
  - Recent uploads
- Graphs and analytics

### 5.2 Attendance Management
- Mark daily attendance
- View attendance reports

### 5.3 Fee Tracking System
- Track paid/unpaid fees
- Monthly reports
- Export reports (CSV)

### 5.4 Role-Based Authentication
- Secure login system
- Different dashboards for Admin/Teacher/Student

### 5.5 Search & Filter System
- Quick search across:
  - Students
  - Notes
  - Videos

---

## 6. 🎨 UI/UX Design Requirements

### 6.1 Design Style
- Clean and minimal
- Modern dashboard layout
- Soft color palette (Blue/White/Yellow)

### 6.2 UI Components
- Sidebar navigation
- Top navbar with notifications
- Cards for stats
- Modal forms for adding/editing data
- Tables with pagination

### 6.3 Default Buttons
- Add Student
- Send Reminder
- Upload Notes
- Upload Video
- Save / Cancel
- Edit / Delete
